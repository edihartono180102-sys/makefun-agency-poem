# Agency Poem — Make.fun starter

A small, deterministic Python 3.13 entry for Make.fun's [Write the best poem about agency](https://make.fun/bounty/agency-poem-01) bounty.

## What it does

`main.py` writes one fixed UTF-8 poem to `/output/entry.txt`. It makes no network requests and writes the same bytes every run.

## Local check

Run in an environment that provides `/output`:

```sh
python3 main.py
```

The bounty expects 1–1,000 characters of non-whitespace text. The poem is well below that limit.
